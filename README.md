# 课件提取器 (Slide Content Extractor)

> 一个运行在浏览器里的油猴脚本，帮你把「互动式网页课件」里的文字一键逐页提取出来，
> 并自动生成带「AI 整理指令」的文档，方便后续让 AI 一键整理成结构化笔记。

适合人群：需要把网页课件（非图片、非 PDF）里的知识点导出做笔记的同学，尤其是非技术背景用户。

### 非计算机专业同学使用须知

本仓库中的脚本为**脱敏示例版**，头部域名是示例地址，不能直接在你的课件页运行。如果你不是计算机专业，不需要手动改代码，可以按下面方式让 AI 帮你修改：

1. 下载仓库里的 `courseware-extractor.js`。
2. 把脚本内容完整复制给 AI，并说明：  
   **“请帮我把脚本头部的 @match 示例域名改成我的课件真实域名，其他代码不要改动。”**
3. 打开你的课件页面，复制浏览器地址栏里的网址。
4. 把课件网址一起发给 AI，让它识别外层地址和课件 iframe 地址。
5. AI 返回修改后的脚本后，把它粘贴进 Tampermonkey 并保存。
6. 刷新课件页面，右下角出现按钮即可使用。

如果你不确定课件 iframe 地址，可以在课件区域右键，选择「检查」或「查看框架来源」，把相关截图一起发给 AI 判断。

注意：**本地修改后的脚本不要上传到公开 GitHub 仓库**，公开仓库只保留脱敏示例版。

## 一、它能解决什么问题

很多在线教学平台（本项目适配「在线教学考评平台」）的课件并不是图片或 PDF，
而是用 JavaScript 渲染在一个**独立的 iframe 小窗口**里的互动页面。

这带来两个麻烦：

1. 直接复制 / 全选很难把每一页都拿到，要手动翻几十页；
2. 网页外壳（登录信息、菜单栏、答题控件等）会混进来，正文反而抓不到。

本脚本专门解决这两点：它自动钻进课件所在的 iframe 内部，**模拟翻页 -> 逐页抓取正文 ->
自动去重 -> 导出文档**，并在文档开头写好一段「交给 AI 整理笔记」的指令。

---

## 二、核心功能

| 功能 | 说明 |
| --- | --- |
| 一键提取 | 在网页右下角出现一个按钮，点一下即可自动逐页抓取整份课件 |
| 穿透 iframe | 通过「双域名注入 + 内外层消息通信」抓到的就是课件正文，而不是网页外壳菜单 |
| 页数自动探测 | 读取课件页码指示器（如 `2 / 37`）自动得到总页数，不同章节无需手改；并带「连续两页不变自动停止」兜底 |
| 自动去重 | 把每页重复出现的页码、菜单等壳文字在导出时合并 / 剔除 |
| 按钮外置 | 提取按钮与进度提示显示在整个浏览器页面的右下角，不挡课件 |
| 自带 AI 整理指令 | 导出文件开头附一段说明，告诉 AI 这是 iframe 抓取的文字、需要删除哪些重复信息、代码用 Markdown 代码块包裹、并输出 Word 版 + MD 版 |

## 三、使用方法（3 步）

1. 安装浏览器油猴插件 **Tampermonkey**（Chrome / Edge 应用商店搜索即可）。
2. 打开 Tampermonkey 管理面板 -> 新建脚本 -> 把 `courseware-extractor.js` 的内容全选粘贴进去 -> `Ctrl + S` 保存。
3. 打开课件页面，按 `F5` 刷新，点击**右下角**出现的粉色「提取课件正文」按钮，等待它自动翻完所有页并下载文档。

> 文件名会自动带上识别到的章节名，例如 `课件笔记_第X章×××.doc`。

---

## 四、导出文档里自带的「AI 整理指令」作用

导出的文件顶部有一段黄色指令框，你直接把整份文件丢给 AI，AI 会据此：

- 知道这是网页课件 iframe 抓取的纯文字（不是图片 / PDF，无需 OCR）；
- 删除每页重复的网页壳文字（页码页眉、`课程中心 / 翻页 / 目录 / 全屏`、`运行 / 编辑 / 放大`、运行时加载提示等）；
- 合并被运行时提示挤断的句子，整理成章节化笔记；
- 把老师演示的代码统一用 Markdown 代码块（如 ` ```python `）包裹，便于阅读；
- 同时输出 Word 版和 Markdown 版。

---

## 五、适配范围与可扩展

脚本默认匹配以下两个域名（在线教学考评平台的登录外壳与课件放映层）：

```
*://outer.example.com/*
*://deck.example.com/*
```

如果你的平台域名不同，只需修改脚本头部 `// @match` 行，改成你自己课件 iframe 的地址前缀即可复用。

## 六、注意事项

- 仅用于**个人学习笔记整理**，请遵守所在平台的版权与使用条款，不要用于传播他人课件内容。
- 脚本只读取你**自己已登录、有权限查看**的课件页面，不向外部上传任何数据。
- 翻页抓取依赖课件支持 `←` / `→` 键翻页；若某章翻页无效，可能需调整脚本中的翻页方式。
